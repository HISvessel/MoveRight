# User Stories

1. As a <ins>new user</ins>, I want to create an account so that I can start using MoveRight's progress tracker and/or account preferences/personalization.
2. As a <ins>new trainee</ins>, I want to record my workout and get form correction so that I can improve my technique.
3. As a <ins>regular user</ins>, I want to track my form improvement over time so that I can see my progress and stay motivated.      
4. As a <ins>trainer</ins>, I want to open the application camera window and put my client in frame, and capture his workout in order to save session data in order to show client correct technique.
5. As an <ins>admin</ins>, I want to view user activity so I can identify inactive users and improve app usage.
6. As an <ins>admin</ins>, I want to view app performance stats so I can debug and fix bugs before they reach users.
