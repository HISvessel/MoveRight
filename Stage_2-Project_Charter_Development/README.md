This is the second stage of the final project, where we are more focused on the technical and planning development of the final product to resent on demo day for Nov 14, 2025. To structure our project more concisey, we took the phases approach to divide how the idea and product development are going to be staged throughout its various phases.


Roadmap:
-> This roadmap entails how we are creating the entire document by the end of this project phase. The roadmap will be divided in two differemt sections: the sub-roadmap for the Back-End, and the sub-roadmap for the Front-End.


Phase 0 -> Research:
-> During this period, we are creating the foundation for which we are going to develop our entire software. To do that, we are taking this phase to familiarize ourselves with all of the languages, tools, builtins, frameworks, shipping products and hardware that we'll use to develop the web app.

For the back-end, our Phase 0 will be looking at each usable module to generate our server side logic. The modules and packages that we will use are the following: OpenCV and MediaPipe for capturing and processing of images, plus for the pose estimation(body detection) modules, NumPy as the placeholder objects for which the processed data will be stored in for further analysis and documentation, Pandas for the spreadsheet that will take as arguments the information passed unto the NumPy arrays, and SciKit-Learn will be the small Machine Learning tool that will make interpretations from the data recieved. 

For the front-end, Phase 0 is also the period where we will explore all the tools and frameworks necessary for the front end development. These are some of the tools that we will use: HTML5, CSS5, JavaScript, React, and ExpressJS(optional, additional).

This phase of the project will make sure that we do enough research of our tools, get familiar with them, and utilize them at the time of development.
